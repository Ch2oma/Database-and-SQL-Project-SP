# Database-and-SQL-Project-SP
Bu proje, SQL eğitiminde öğrenilen veritabanı tasarımı, tablo oluşturma, ilişkilendirme (Foreign Key), veri manipülasyonu (DML) ve karmaşık sorgu yazma (JOIN, GROUP BY, Subquery, View) becerilerini gerçek hayat senaryosu üzerinde uygulamak amacıyla geliştirilmiştir.

Senaryo gereği "NovaStore" adlı yeni kurulan e-ticaret sitesinin Veritabanı Yöneticisi (DBA) olarak; ürünlerin, müşterilerin, kategorilerin ve siparişlerin tutulacağı ilişkisel bir veritabanı tasarlanmış, örnek verilerle doldurulmuş ve yönetim kurulu için kritik raporlama sorguları hazırlanmıştır.
